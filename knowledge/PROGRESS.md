# PROGRESS — 周回の履歴

MAPE-K の各周回の記録（ADR-0010）。Monitor が観測サイクルを、Execute が実装ラウンドを追記する。
過去施策の効き目もここに溜まるので、周回ごとに判断が良くなる。

新しい記録は**末尾に時系列で追記**する（`mape/run.sh` と Execute スキルの両方が末尾追記する）。
フォーマットは下記の見出しテンプレートに従う。

## テンプレート（コピーして使う）

```
## YYYY-MM-DDTHH:MMZ — <cycle: monitor | execute>
- 対象: <イシュー/項目/シグナル>
- やったこと: <要約>
- 結果: <pass/fail・PR #N・revert 等>
- 考察: <なぜそうなったか・効き目>
- 次に必要になった作業: <BACKLOG へ回すもの>
```
